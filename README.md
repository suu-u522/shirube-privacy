# しるべ — プライバシーポリシー

iPad アプリ「[しるべ](https://github.com/suu-u522/shirube)」のプライバシーポリシーを公開するためのリポジトリ。

**公開先:** https://suu-u522.github.io/shirube-privacy/

App Store Connect の「プライバシーポリシー URL」にこの URL を登録する。

## なぜアプリ本体と別のリポジトリなのか

アプリのリポジトリで GitHub Pages を有効にすると、`docs/` に置いてある教材資料や設計書まで一緒に公開されてしまう。ポリシーだけを出したいので分けている。

## 内容の正・写しの関係

**アプリが表示している内容が正で、このページはその写し。**

同じ内容がアプリの中（トップ画面下部の「このアプリについて」）に表示される。ポリシーは外部のページへのリンクではなく本文をアプリに持たせており、その理由は本体リポジトリの `docs/spec/shirube.md` に書いてある（リンクを踏むと Safari が開き、生徒が触っている端末がブラウザに切り替わってしまうため）。

**内容を変えるときは、先にアプリ側（`Shirube/Home/AboutView.swift` の `AppInfo.dataPoints`）を直し、それに合わせてこのページを更新する。** 逆をやると、実物と表示が食い違ったまま公開されることになる。

## 日本語と英語を併記している理由

App Review の担当者が日本語話者とは限らない。データを収集しないことを英語でも読めるようにしてある。
